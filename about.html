关于刮刮乐大亨

一款免费的网页模拟经营游戏。在街角彩票店当彩民，一路刮成大亨。

开始游戏

这是什么游戏

你扮演住在幸福路的一个普通人。在彩姐的彩票店买刮刮乐，用指甲、硬币或者电钻把刮膜刮开，和店里的老主顾聊天、帮他们跑腿，攒够本钱以后盘下一家店，自己当老板。游戏里有十几款刮刮乐、四种电脑票、十五种刮具、全服排行榜，还有别的玩家开的彩票店可以逛。

这不是什么

刮刮乐大亨是模拟游戏，不是博彩。游戏里的钱全部是虚拟的：不能用真钱买，不能换成真钱，也没有任何付费内容。游戏里的彩票、发行机构、店铺和人物都是虚构的，与任何真实的彩票机构没有关系。游戏面向成年玩家。

现实中的彩票中奖率远低于游戏。请理性看待，量力而行。

About (English)

Scratch Tycoon is a free browser simulation game. You start as a punter at a corner lottery shop, scratch tickets, run errands for the regulars and eventually open a shop of your own. All money in the game is virtual: there are no purchases and no cash-outs. Every ticket, issuer, shop and character is fictional and has no connection to any real lottery organisation. The game is intended for adults. An English interface is available from the language switch on the sign-in screen.
